# 📧 Phishing Email Analysis

This repository contains phishing email samples, header analysis, indicators, 
and complete documentation for identifying phishing attempts.

## 📂 Repository Structure
- `samples/` — Raw phishing email samples & headers  
- `analysis/` — Detailed phishing analysis reports  
- `screenshots/` — Proof screenshots (body, headers, links)  
- `tools/` — Useful tools for header & URL analysis  
- `docs/` — Educational content  
- `assets/` — Icons, diagrams, illustrations  

## 🛡️ Purpose
This repo helps users learn how to:
- Identify phishing emails  
- Analyze suspicious headers  
- Detect malicious links  
- Understand common red flags
